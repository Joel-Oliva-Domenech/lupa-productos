# Seguridad

## Versiones compatibles

La rama principal es la única versión que recibe correcciones de seguridad durante la etapa
inicial del proyecto.

## Informar de una vulnerabilidad

No publiques una vulnerabilidad explotable en un issue abierto. Usa la función privada
“Report a vulnerability” de GitHub Security Advisories en el repositorio.

Incluye una descripción, pasos mínimos para reproducirla, impacto estimado y una propuesta de
mitigación si la tienes. Evita adjuntar datos personales o secretos reales.

## Datos sensibles

Lupa no necesita cuentas ni almacena datos en un servidor propio. Historial y preferencias
permanecen en el navegador. Aun así, cualquier cambio que añada telemetría, autenticación o
sincronización debe documentar consentimiento, retención y borrado antes de incorporarse.
